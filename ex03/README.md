# Git Workflow Project

## Introduction
This project helps me practice Git and learn how to manage code changes.

## Why Git Makes Development Easier
Git keeps track of code changes and saves the project history. If something goes wrong, I can return to an earlier version. It also helps developers share their work and collaborate easily.

## Basic Workflow
1. **Edit:** Make changes.
2. **Add:** Prepare changes using `git add`.
3. **Commit:** Save changes using `git commit`.
4. **Push:** Upload changes using `git push`.
